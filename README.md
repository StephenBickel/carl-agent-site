# Carl Agent site

The public landing page for [Carl Agent](https://github.com/StephenBickel/carl-agent), a local-first Rust agent built around replayable events, explicit approval boundaries, and interchangeable models.

## Local development

```bash
npm install
npm run dev
```

## Production

The site is deployed on Vercel at [carlagent.ai](https://carlagent.ai).

```bash
npm run build
npm run lint
```
